GitHub Pages fallback is live.

The full LifePage product is a dynamic Next.js app with auth, billing, APIs, and Cloudflare deployment logic. GitHub Pages cannot host that runtime, so this site is a lightweight landing page instead of the full app.

Current status

This repository now has a valid Pages landing page. The full app deployment is being served through Cloudflare Workers when the target account and bundle size constraints are satisfied.
